## SaaS/Hosted Platforms

- **[Browserbase](https://browserbase.com)**  
  Serverless cloud headless browser infrastructure for AI agents and web automation featuring managed stealth mode, residential proxies, session replay, and live debugging.

- **[Steel.dev Cloud](https://steel.dev)**  
  Managed browser-as-a-service API engineered for AI agents offering persistent browser sessions, captcha solving, proxy rotation, and instant CDP connections.

- **[Hyperbrowser](https://hyperbrowser.ai)**  
  Scalable cloud browser infrastructure for AI web agents providing stealth sessions, built-in scraping/crawling APIs, and isolated sandboxed browsers.

- **[Anchor Browser](https://anchorbrowser.io)**  
  Cloud browser infrastructure built for AI agents featuring persistent authenticated profiles, anti-bot evasion, and real-time human-in-the-loop takeover.

- **[Browserless](https://browserless.io)**  
  Managed cloud fleet of headless Chrome browsers supporting Puppeteer, Playwright, and raw CDP connections with session recording and concurrency scaling.

- **[MultiOn](https://multion.ai)**  
  Autonomous personal and enterprise AI web agent platform capable of executing multi-step browser tasks, bookings, and research across live websites.

- **[Induced AI](https://induced.ai)**  
  Cloud browser-native RPA and autonomous workflow platform translating natural language SOPs into parallel headless browser executions.

- **[Skyvern Cloud](https://skyvern.com)**  
  Hosted vision-LLM browser automation platform automating complex form-filling, procurement, and portal workflows without brittle XPath selectors.

- **[Scrapfly](https://scrapfly.io)**  
  Cloud web scraping and browser rendering API featuring Anti-Scraping Protection bypass, headless browser sessions, and AI extraction endpoints.

- **[Airtop](https://airtop.ai)**  
  Cloud browser automation infrastructure designed for AI agents to interact with authenticated web apps using natural language and live human intervention.

- **[Browser Use Cloud](https://browser-use.com)**  
  Managed cloud runtime and stealth browser hosting built specifically for scaling open-source `browser-use` AI web agents in production.

## Open-Source GitHub Projects

- **[Page Agent (alibaba/page-agent)](https://github.com/alibaba/page-agent)**  
  MIT-licensed open-source JavaScript in-page GUI agent that embeds directly into any web application via one script tag, using text-based DOM dehydration to control interfaces via natural language without computer vision or headless browsers.

- **[QZ Browser Agent (alibaba/qz-browser-agent)](https://github.com)**  
  Local-first open-source Chrome extension agent from Alibaba supporting autonomous browser automation, web research, MCP tool connections, and BYO local/cloud LLMs.

- **[Browser-Use (browser-use/browser-use)](https://github.com)**  
  The most popular open-source Python framework connecting LLMs with Playwright browsers so AI agents can autonomously click, type, scroll, manage tabs, and extract data.

- **[Stagehand (browserbase/stagehand)](https://github.com)**  
  Open-source AI web browsing framework built on Playwright combining natural-language `act`, `extract`, and `observe` primitives with deterministic TypeScript/Python code and self-healing caching.

- **[Steel Browser (steel-dev/steel-browser)](https://github.com)**  
  Self-hostable open-source browser sandbox and API container built on Puppeteer/Playwright with session management, extension loading, and CDP exposure for AI agents.

- **[Skyvern OSS (Skyvern-AI/skyvern)](https://github.com)**  
  Open-source AI browser automation engine combining computer-vision LLMs and Playwright to navigate unfamiliar websites and automate multi-step workflows reliably.

- **[Playwright (microsoft/playwright)](https://github.com)**  
  Industry-standard open-source cross-browser automation framework for Chromium, Firefox, and WebKit providing auto-waiting, network interception, and accessibility tree snapshots.

- **[Playwright MCP (microsoft/playwright-mcp)](https://github.com-mcp)**  
  Official Microsoft Model Context Protocol (MCP) server enabling LLMs (Claude, Cursor, Codex, Gemini) to control real browsers via structured accessibility snapshots rather than fragile screenshots.

- **[Chrome DevTools MCP (ChromeDevTools/chrome-devtools-mcp)](https://github.com)**  
  Official Google Chrome DevTools MCP server giving AI coding and browsing agents direct access to live browser inspection, network logs, console traces, and DOM actions.

- **[Nanobrowser (nanobrowser/nanobrowser)](https://github.com)**  
  Open-source multi-agent AI web automation Chrome extension serving as a free, self-hosted alternative to OpenAI Operator and MultiOn with support for local Ollama and cloud LLMs.

- **[LaVague (lavague-ai/LaVague)](https://github.com)**  
  Open-source Large Action Model (LAM) framework combining a World Model planner and Action Engine to automate web workflows over Selenium and Playwright.

- **[Agent-E (EmergenceAI/Agent-E)](https://github.com)**  
  Open-source hierarchical multi-agent browser automation system built on AutoGen and Playwright utilizing distilled DOM representations for high-accuracy web navigation.

- **[SeeAct / WebArena / VisualWebArena (OSU-NLP-Group/SeeAct)](https://github.com)**  
  Foundational open-source multimodal web agent research framework grounding Large Multimodal Models (LMMs) onto live HTML elements and browser screenshots.

- **[Magnitude (magnitudedev/magnitude)](https://github.com)**  
  Open-source AI-native browser automation and end-to-end testing framework driven by vision-first natural language actions and resilient self-healing selectors.

- **[Midscene.js (web-infra-dev/midscene)](https://github.com)**  
  ByteDance's open-source AI-powered UI automation SDK for Web, Android, and iOS enabling natural-language actions, assertions, and JSON data extraction over Playwright and Puppeteer.

- **[Browserless OSS (browserless/browserless)](https://github.com)**  
  Self-hostable open-source Docker container and API server managing headless Chrome instances with concurrency queuing, live debugger UI, and Puppeteer/Playwright support.

- **[Patchright (Kaliiiiiiiiii-Vinyzu/patchright)](https://github.com)**  
  Undetected open-source fork of Playwright for Python and Node.js that eliminates CDP `Runtime.enable` leaks so AI web agents avoid bot detection.

- **[Camoufox (daijro/camoufox)](https://github.com)**  
  Open-source anti-detect Firefox browser with C++-level fingerprint spoofing designed for stealth Playwright automation and resilient AI web agents.

- **[Nodriver (ultrafunkamsterdam/nodriver)](https://github.com)**  
  Asynchronous, WebDriver-free Python browser automation framework communicating directly over CDP for fast, stealthy web agent execution.

- **[Puppeteer (puppeteer/puppeteer)](https://github.com)**  
  Official Chrome DevTools open-source Node.js library providing high-level automation APIs over Chrome and Firefox via CDP and WebDriver BiDi.

- **[Selenium (SeleniumHQ/selenium)](https://github.com)**  
  Foundational open-source W3C WebDriver browser automation ecosystem supporting Python, Java, JS, C#, and Ruby across all major browsers.

- **[Crawlee (apify/crawlee)](https://github.com)**  
  Production-grade open-source browser automation and crawling library for Node.js and Python featuring persistent request queues, proxy rotation, and fingerprint management.

- **[Cua / Open Operator (trycua/cua)](https://github.com)**  
  Open-source computer-use and browser sandbox infrastructure allowing vision-language agents to control isolated macOS/Linux virtual machines and browsers safely.

- **[UI-TARS Desktop (bytedance/UI-TARS-desktop)](https://github.com)**
